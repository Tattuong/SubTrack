# SubTrack

Remember a renewal before it charges. Plans, prices, dates, links, and cancel notes stay on this phone.

Package: `com.SubTrackMNG.SubTrack`

Remote config: [N311.json](https://api2.blwsmartware.net/N311.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product | Type |
| --- | --- |
| `st_pack_1` … `st_pack_10` | Consumable coins |
| `st_remove_ads` | Non-consumable |
| `st_pro` | Non-consumable, more than 8 plans |

SubTrack does not read a bank account and does not cancel a service.
